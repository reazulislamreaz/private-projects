# Selected Private Projects

This repository contains a selection of my professional software projects that are currently deployed in production or were developed for clients.

## About This Repository

The source code of these projects is kept private because some of the applications contain confidential business logic, proprietary code, client data, infrastructure configurations, and other sensitive information.

For this reason, the projects cannot be published as public repositories.

This repository is intended primarily for recruiters, hiring managers, and potential clients who would like to learn more about my professional development experience and the systems I have worked on.

## Why Is the Source Code Private?

The repositories are private due to requirements such as:

- Client confidentiality
- Production security
- Intellectual property protection
- Proprietary business logic
- Sensitive infrastructure and configuration
- Contractual restrictions on publicly sharing source code

Keeping these projects private does not mean the work cannot be reviewed.
